## 残る本人操作

1. 公開アプリにGoogleでログインし、「音声で依頼」→「録音を開始」。
2. ブラウザーのマイク許可後、「来週金曜日までに、3分の番組の企画案と台本を作って」等と発話して録音を終了。
3. 実際の発話に対応した文字起こしを確認し、必要なら修正。
4. 「案件案を作成」→案件名・期限・概要・テンプレートを確認→登録。
5. 再読み込み後も案件が残ることを確認。

文字起こしの言い間違い・固有名詞の誤認識は修正可能だが、収録失敗、空の認識結果、登録・永続化失敗は不合格として修正する。テスト音声を作って流すことを本人のマイク収録成功とは数えない。
