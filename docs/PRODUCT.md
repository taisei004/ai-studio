# 製品仕様 v0.1

個人の制作ディレクターが、専門AI社員に依頼し、進捗と成果物を確認し、要所で判断するローカル制作オフィス。

## 画面

オフィス / 案件管理 / AI社員 / 承認ボックス / 成果物 / 設定。
オフィス中央に7エリア（6職種の制作席とラウンジ）、右に選択社員の情報を配置。操作は通常のHTMLボタンとフォームにし、Canvasに依存せず社員を選択できる。

## 初期案件

パレプロEX 番組制作。工程は企画リサーチ→企画承認→台本制作→台本確認→サムネ構成→素材案作成→最終レビュー。最初は全工程未着手。各工程の前にそれ以前の全工程の完了が必要。

## 状態と承認

- 開始: 待機またはエラー→作業中。
- 成果物を作成: 作業中→承認待ち。モック成果物と承認レコードを生成。
- 承認: 完了。次の工程が開始可能になる。
- 修正依頼: コメント必須で作業中へ戻す。旧成果物・承認履歴を保存。
- 保留: 承認待ちのまま。後で承認・修正できる。
- エラー検証: 作業中→エラー。開始ボタンで再試行。
- 進捗: 完了工程数÷全工程数。モック実行の経過時間では増えない。

社員状態は選択中の案件内のタスクから集計。優先順位はエラー→承認待ち→作業中→全タスク完了→待機。AI社員一覧では全案件から集計する。

## v0.1に含めないもの

実モデル接続、CLI起動、自律実行、歩行アニメーション、会議演出、複数端末同期、ログイン、成果物の直接編集、タスクの自由追加・担当変更、バックアップのインポート。案件ごとの担当はテンプレートで固定。

## 受け入れ条件

ローカル起動、6人の社員選択、案件CRUDと再起動後の保存、プロフィール編集、状態と進捗の連動、承認3操作、成果物閲覧・書き出し。ビルドとワークフローテストを通過する。
