# AI STUDIO v0.2

対象: PCブラウザーで使う個人向けAI制作管理アプリ。

## 2026-10-19の追加要件

ユーザーの追加依頼により、v0.1のピクセルデスク・モック・ローカルバックエンドから変更。PC Web、部屋による作業の可視化、音声入力、白基調Liquid Glass、アニメーション、全画面スケルトン、Cloudflare、Workers AI、Googleのみの認証、GitHubと公開を対象とする。挨拶や宣伝的キャッチコピーは表示しない。

## 所在

待機/完了→ラウンジ。作業中→Producerは会議室、Researcherはリサーチ室、Writer/Material ArtistはPCルーム、Designerは制作室、Reviewerはレビュー室。承認待ち→会議室。エラー→レビュー室。
全体の稼働数は全案件、オフィスの所在は選択案件のタスクから計算する。画面上部で表示案件を切り替える。

## 操作

- 案件: 作成、編集、削除、検索。番組/Web/映像/カスタムテンプレート。
- 社員: 名前、役割、得意分野、カスタム指示の編集。
- タスク: 開始、Workers AIで生成、承認、修正依頼、保留、エラー再試行。
- 前工程が承認済みになるまで後工程を開始しない。
- 進捗は承認済み工程÷全工程。時間で自動完了しない。
- 作業ログと成果物履歴。Markdown保存、JSONバックアップ。
- 音声入力: 録音（最大60秒）または音声ファイル（最大8MB）→文字起こし→内容の整理→フォームで確認→登録。入力された操作を無条件に実行しない。
- Googleログイン・ログアウト。ログインしたユーザーごとにデータ分離。
- アニメーション低減設定、OSのReduced Motion、透過低減・コントラスト設定への対応。

## 制限

AIは文章生成と音声文字起こし。Web検索、コード実行、画像生成、外部ファイル操作は未実装。リサーチ成果は未検証の提案として扱う。
工程はテンプレートの直列。タスク自由編集、共同編集、実行キャンセル、音声による削除、データ復元、旧DB移行は未実装。
Google認証は公開環境で実接続を確認済み。実マイクの収録はユーザーのマイク許可と発話が必要で、本人が現在発話できないため未検証。
