# 開発ロードマップ

## v0.1 基盤

- ピクセルオフィス、社員選択、状態連動。
- 案件CRUD、番組制作の固定テンプレート。
- 明示的モック操作、承認、修正、保留。
- SQLite保存、成果物・作業ログ。
- テスト、起動手順、Claudeへの引き継ぎ。

## v0.2 最初の実AI

1. 利用可能なCodex / ClaudeのCLI・認証・契約範囲を確認。
2. Storeを正規化し、ジョブ・競合制御・キャンセルを実装。
3. Researcher一人を接続し、企画案→承認待ちを通す。
4. イベント配信による進捗更新、再起動時の中断復旧。
5. 引き継ぎ可能な実行ログと成果物ファイル参照。

## v0.3 制作ワークフロー

台本・サムネ・素材工程、工程別成果物、実務での時間削減と品質を検証。タスク追加・担当割当、テンプレート編集、並列工程、依存関係。

## その後

オフィスの移動や書類配送、ピクセル素材の作り込み、他用途テンプレート、デスクトップ化。品質と実務導線を確認してから追加する。
